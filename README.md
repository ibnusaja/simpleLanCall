1. Audio tidak dikompres (sekitar 256 kbps). Ini aman di WiFi lokal, tapi tidak cocok untuk internet.
2. Kalau terdengar gema, pakai earphone.
3. Tidak ada jitter buffer atau enkripsi, supaya kodenya tetap sederhana.
4. Jika koneksi tidak masuk, cek apakah router mengaktifkan "AP/client isolation", karena fitur itu memblokir komunikasi antar perangkat.
